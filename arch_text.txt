4.2. Sessiya qulflash — qattiq
Har login'da yangi session_id yaratiladi
Eski session_id Redis blacklist'ga tushadi
Middleware har so'rovda session_id ni tekshiradi
Login uchun rate limit: 3 xato → 5 daqiqa blok
4.3. Yangi qurilma tasdig'i (Variant C+)
Birinchi kirish (yangi qurilma):
Login + parol kiritiladi
Kamera ochiladi → selfi olinadi
Qurilma ma'lumotlari (browser fingerprint, IP, user-agent) + selfi admin paneliga tushadi: "Tasdiq kutilmoqda"
Xodim "Admin tasdig'ini kutmoqdasiz" sahifasini ko'radi
Admin tasdiqlaydi → xodim kiradi, qurilma "ishonchli" bo'lib saqlanadi
Admin rad qilsa → kirish ruxsat etilmaydi
Keyingi kirishlar (ishonchli qurilma):
Login + parol → selfi olinadi → tarixga saqlanadi
Xodim darhol kiradi (admin tasdig'i kutilmaydi)
Admin "Login tarixi" da har kirish selfi bilan ko'radi
Xavf signallari (avtomatik):
Noma'lum IP dan kirish
Bir kunda 5+ marta xato parol
Bir kunda 5+ marta chegirma (15%+) berilgan
4.4. Parol xavfsizligi
bcrypt (12 rounds)
Rate limit: 3 xato → 5 daqiqa blok
JWT: 15 daqiqa | Refresh token: 7 kun (HTTP-only cookie)

7. BAR KOD TIZIMI
7.1. Format
SH-MIC-19565R15-000001
│   │   │        └── 6 xonali tartib raqami (999,999 gacha)
│   │   └────────── Razmer (195/65R15 → 19565R15, bo'sh joy va "/" olib tashlanadi)
│   └────────────── Brend qisqartmasi (Michelin → MIC, 3 harf)
└────────────────── Kategoriya prefiksi (SH=Shina, DS=Disk, AK=Aksessuar, XZ=Xizmat)
Misollar:
Michelin 195/65 R15   → SH-MIC-19565R15-000001
Lassa 215/55 R17      → SH-LAS-21555R17-000001
Bridgestone 205/65 R15 → SH-BRI-20565R15-000001
BBS R17 disk          → DS-BBS-R17-000001
Borbet R18 disk       → DS-BOR-R18-000001
Mobil 5W-30 moy       → AK-MOB-5W30-000001
Montaj xizmati        → XZ-MON-000001
Qoida:
Raqam 000001 dan boshlanadi, ortadi
999999 dan keyin 7 xonaga o'tadi (avtomatik)
Hech qachon takrorlanmaydi (DB'da UNIQUE constraint)
7.2. Chop etish jarayoni
Kirim qilingandan keyin "Bar kod yaratish" tugmasi
Tizim barcha yangi tovarlar uchun bar kod yaratadi
"Chop etish" tugmasi → PNG rasmlar (Niimbot/Phomemo o'lchamlari: 40×30mm, 50×30mm)
Telefonga yuborish yoki to'g'ridan-to'g'ri Niimbot ilovasida ochish

9. SODIQLIK TIZIMI (TALON) — TO'LIQ OQIM
1. Yangi mijoz → "Talon berish" tugmasi
   → LoyaltyCard yaratiladi (T-2026-000142)
   → Niimbot'dan talon chiqariladi (QR kod + mijoz ismi + 10 ta bo'sh doira)
   → Sotuvchi qog'oz talonga muhr bosadi (1-xarid)
   → stampsCount = 1

2. Keyingi xaridlarda:
   → Mijoz talon ko'rsatadi → sotuvchi skaner qiladi yoki raqam kiritadi
   → Tizim: "Jasur Toshmatov — 7-chi xaridi, 3 ta qoldi"
   → Sotuvchi qog'oz talonga muhr bosadi
   → stampsCount += 1

3. 10-chi xaridda (stampsCount = 9 → 10):
   → Ekranda: "🎉 TABRIKLAYMIZ! Bu mijozning 10-chi xaridi!"
   → "Chegirmani qo'llash" tugmasi chiqadi
   → Mijoz: shina yoki disk, nechta dona tanlaydi
   → 25% chegirma o'sha tovar(lar)ga qo'llaniladi
   → Sotuv yakunlanadi, LoyaltyRedemption saqlanadi
   → stampsCount = 0 (yangi davr boshlanadi)
   → Yangi talon chiqariladi (ixtiyoriy)

4. Agar 10-chi xaridda shina/disk yo'q:
   → stampsCount = 10 bo'lib qoladi
   → Keyingi shina/disk xaridida avtomatik chiqadi

13. HISOBOTLAR VA FILTRLAR
13.1. Sotuv hisoboti
Filtrlar:
Sana oralig'i (kun/hafta/oy/yil/mavsum/individual)
Filial
Sotuvchi
To'lov turi (naqd/karta/muddatli)
Kategoriya
Brend
Mavsum (yoz/qish/butun yil)
Ko'rsatkichlar:
Jami sotuv summasi
Jami foyda
O'rtacha chek
Eng ko'p sotilgan tovarlar (TOP 10)
Eng kam sotilgan tovarlar (BOTTOM 10)
Brend bo'yicha sotuv
Kategoriya bo'yicha sotuv
Mavsumiy tahlil (yoz vs qish)
13.2. Qoldiq hisoboti
Filtrlar: Filial, kategoriya, brend, mavsum, holat (normal/kam/to'xtab qolgan)
Ko'rsatkichlar:
Umumiy qoldiq (soni va summasi)
Kam qolgan tovarlar (threshold'dan past)
To'xtab qolgan tovarlar (60+ kun sotilmagan)
"Qotib qolgan kapital" — sotilmagan tovarlarning kirim narxi
Partiya bo'yicha narx tarixlari
13.3. Foyda hisoboti
Kirim − Sotuv − Xarajat = Sof foyda
Filial bo'yicha solishtirish
Oylik trend grafigi
Eng foydali kategoriya/brend/tovar
13.4. Xodimlar hisoboti
Har xodim: sotuv soni, summasi, foydasi
Reyting jadval
Berilgan chegirmalar
Bekor qilingan sotuvlar

16. XAVFSIZLIK PRINTSIPLARI
API kalitlari va secretlar — faqat .env (server side)
Frontend'da hech qanday secret, kirim narxi, foyda raqami ko'rsatilmaydi (sotuvchi uchun)
Har API endpointda permission tekshiruvi
SQL injection — Prisma ORM avtomatik himoya
XSS — React avtomatik escape
CSRF — JWT + SameSite=Strict cookie
Rate limiting — login va AI endpointlarda
HTTPS — production'da majburiy
Kunlik avtomatik backup (pg_dump)
Audit log — har muhim amal saqlanadi
Fayl yuklanishi — faqat ruxsat etilgan formatlar (jpg, png, pdf), hajm cheklovi
Selfi rasmlari — xususiy papkada, URL'ga to'g'ridan-to'g'ri kirish yo'q
